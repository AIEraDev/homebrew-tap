# Homebrew Tap — AIEraDev

Custom Homebrew tap for [Ithqan](https://github.com/AIEraDev/Ithqan) and future AIEraDev applications.

## Installation

```bash
brew tap AIEraDev/tap
brew install --cask ithqan
```

## Available Casks

| Cask | Description |
|------|-------------|
| `ithqan` | Local-first Quran memorization review companion with audio looping and retention tracking |

## Updating

```bash
brew update
brew upgrade --cask ithqan
```
